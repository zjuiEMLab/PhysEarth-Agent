~40 s. Top to bottom. The Studio is a Gradio app whose views are plain strings, so they are testable without a browser, and it talks to the package only through physearth.api, a boundary a test enforces. The agent loop assembles a layered prompt and keeps a session store; model runs return handles and a bounded preview. The 21 tools fall into six groups: seven read papers, figures, datasets and live literature; four plan; three run; two draw; three register new models; two are the raw baseline used in evaluation. The harness is the orange row, and it is code the LLM cannot switch off. The LLM itself is swappable through one OpenAI-compatible client, configured by environment variables.
