The problem

Physical models fail silently

Out of range

Snow density 2000 kg m⁻³, denser than solid ice. SMRT still returns a smooth curve.

Illegal pairing

DMRT with an exponential autocorrelation, a microstructure the theory was never derived for.

Unit slip

A unit off by an order of magnitude. Nothing complains; the curve just moves.

A deep model's bad configuration shows up as a bad score. A physical model's shows up as a believable figure.
