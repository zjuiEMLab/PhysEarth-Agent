~50 s. This is the workflow a scientist sees, using the one case with committed runs. The question is turned into a measurable quantity and a controlled comparison. The source section and figure are opened, and the figure's own title, axes and legend are extracted rather than typed in. The plan labels where every value came from, which is what slide 13 audits. Nothing executes until a person approves, and the person can edit a frequency or drop a run first. Every run is checked against the card's bounds, and the report places the generated figure beside the paper's, cites what was read and run, and declares one of four outcomes, so a partial reproduction is never presented as a full one.
