18

~50 s. Most invariants carry over for free because they already live in code. Two do not. Approval: in the web app a person clicks a button the agent cannot reach; over MCP, any tool we expose the host model can call, so approval must happen outside the tool channel, through MCP elicitation where the client supports it, or a signed ticket confirmed from a terminal or local page. Citations: our gate checks our agent's final answer, but in a plugin the host writes it, so we expose verification as a tool and, in Claude Code, enforce it with a Stop hook. Be honest in the paper that a host's own web search sits outside our untrusted-text boundary.
