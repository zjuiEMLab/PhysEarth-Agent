What the model gets without new code

  • Ranges and legal combinations checked before the run
  • A human approves the run; the agent cannot
  • Outputs checked against declared bounds after it
  • Every claim carries a marker that must resolve
  • Abstract-only evidence may never carry a value
  • Outside text arrives as evidence, never instruction
  • Arrays stay in the session store; the LLM sees handles
  • Charts come from a declarative spec, not agent code

~50 s. The contribution is a contract: a model is a YAML card plus a pure run(spec) function. The card declares ranges, legal combinations and output bounds; the harness enforces them for every model, so the checks are data, not prompt text. The eight invariants on the right are what AGENTS.md calls "the product, not conventions". For the paper, this generality is the claim to defend: that a new model gets all of this with zero harness edits.
