2. Methods paragraph with inline badges

A paragraph a reader can approve without opening a table. The source sits on every number.

We will run SMRT 1.5.1 on a 1 m snowpack default at 265 K default, observed at 37 GHz extracted §07 and 55° default, with 100 µm spheres extracted §08. Density is swept from 1 to 100 kg m⁻³ in 30 steps extracted, figure axis.

Six runs cross three microstructures (independent spheres, non-sticky hard spheres, sticky hard spheres extracted, figure legend) with the two theories the paper pairs with each (Rayleigh or DMRT QCA-CP, and IBA).

The two sticky-sphere runs also need a stickiness, which the paper does not state for this figure. We use the card's 0.2 default and add a sensitivity run at 0.5 assumed: the value the paper uses for Figure 4.

Output. One chart, scattering coefficient against density, six curves, compared with Figure 3. Reproduced if the three families separate in the paper's order and agree near zero density.

Quickest to approve. Hard to edit one value, so it works as a view over one of the other shapes, and as the opening of the report.

3. Base conditions plus variants

The shape the experiment is thought about in: a base, then what each variant changes. Compact and still machine readable.

plan: fig3-sparse-medium
model: smrt 1.5.1
base:                                                 # source
  frequency_ghz: 37                                   extracted smrt-v1#07
  radius_m: 1.0e-4                                    extracted smrt-v1#08
  thickness_m: 1.0                                    default
  temperature_k: 265                                  default
  angle_deg: 55                                       default
sweep: {density_kg_m3: [1, 100, 30]}                  extracted figure axis
variants:
  independent spheres: {microstructure: independent_sphere,      theory: [rayleigh, iba]}
  non-sticky hard:     {microstructure: non_sticky_hard_spheres, theory: [dmrt_qcacp_shortrange, iba]}
  sticky hard:         {microstructure: sticky_hard_spheres,     theory: [dmrt_qcacp_shortrange, iba],
                        stickiness: 0.2}              default
sensitivity:
  stickiness: [0.1, 0.5]                              assumed brackets the card default
figures:
  - {id: fig3, x: density_kg_m3, y: ks_per_m, draws: all variants x theories}

Smallest to store, easiest to extend: six runs become three lines because a variant can list several theories. The planner expands it into runs, so six copies cannot drift apart.

4. Figure-first plan

Starts from the paper's figure and says what each curve is, so the reviewer checks the plan against the thing being reproduced.

TARGET   Figure 3, "Sparse-medium scattering coefficient comparison" (Picard et al. 2018)

x axis   Density (kg m⁻³), 0 to 100   extracted
y axis   Scattering coefficient (m⁻¹)   extracted

Curves: the paper's legend, then what we run

"Independent spheres (Rayleigh)"→R1 independent_sphere + rayleigh
"Independent spheres (IBA)"→R2 independent_sphere + iba
"Non-sticky hard spheres (DMRT QCA-CP)"→R3 non_sticky_hard_spheres + dmrt_qcacp
"Non-sticky hard spheres (IBA)"→R4 non_sticky_hard_spheres + iba
"Sticky hard spheres (DMRT QCA-CP)"→R5 sticky_hard_spheres + dmrt_qcacp
"Sticky hard spheres (IBA)"→R6 sticky_hard_spheres + iba

Conditions for all curves

37 GHz extracted · 100 µm extracted · 1 m default · 265 K default · stickiness 0.2 default (R5, R6)

The question the report must answer

Over what density range do the six converge, and where do they diverge? The paper gives about 10 to 20 kg m⁻³ for the sparse-medium range [smrt-v1#08].

Judged by: same three families, same order, same shared slope at the origin.

Best for reproduction: curves trace to legend entries, and the question the report must answer is on the plan. Specific to a figure target, since a free-form experiment has no legend.

Suggested combination

Store shape 3: base, variants, sweep, sensitivity and figures, each value with a source tag and a reason for anything assumed. Show shape 5 as the review screen, with shapes 1 and 4 one click away as "show conditions" and "show against the paper". Shape 2 becomes the opening paragraph of the report, generated from the same data. One source of truth, no six copies, and the source tag per value is what the report's provenance table and the parameter-source check already need.

Changing what the agent sends changes the tool contract and the prompt text, so it invalidates comparison with existing evaluation records. It is also the natural point to adopt the draft schema in research-plan-schema/.
