Five templates for a PhysEarth research report

Selection: the figure-led report is the default; a study whose plan targets three or more of the paper's figures is written as an IMRaD manuscript; PHYSEARTH_REPORT_TEMPLATE (figure-led, brief, imrad, ledger or memo) overrides both.

Each template is written for the same constraint: the paper is read once per session into key statements with their sections, and a section is reopened only to check a detail. A report uses those statements, the approved plan, the generated figures and the recorded runs. Each template keeps those three visibly apart and starts with the answer to the user's question.

The five templates

Chips show the report judge's eight criteria each template covers by construction: green fully, amber partly.

01

Figure-led report

Default600-900 words · follows "figure → plan → answer"

Built around the result data (MIT's storyboarding advice), with Georgia Tech-style captions. It follows the order you described: the figure, then the plan behind it, then the answer.

Outline
  1. Answer: two or three sentences answering the question in its own terms, plus the outcome word.
  2. The plan in brief: one paragraph on the model and version, what was held fixed and where each value came from, what was swept, and how many runs.
  3. Figure N, one block per figure:
    • caption: what is plotted, conditions, data source;
    • what it shows: count, order, convergence, divergence, crossings;
    • what the runs measured: statistics the tools computed, otherwise N/A;
    • what it answers.
  4. Against the paper: the plan's recorded findings next to what the figures show (agree, differ, not comparable), each cited.
  5. Assumed values and limits: a table of every value not taken from the paper, then 2-4 limits.
Opening, written from the latest run
The six theory/microstructure combinations converge to one first-order behaviour only at the sparse end and diverge as density rises. The paper puts that range at 10–20 kg m⁻³ [smrt-v1#08]. The recorded runs show the same ordering (sticky hard spheres highest, non-sticky lowest) but do not identify a threshold. Outcome: reproduced qualitatively; the density threshold is not scoreable from these runs.

02

Answer-first brief

Short≤ 450 words · for a reader who needs a decision

Answer first, from CMU's executive-summary advice: the first paragraph alone should let the reader act. Everything after it is support.

Outline
  1. Answer and outcome: one paragraph.
  2. Why we believe it: three bullets, each a figure observation backed by a run statistic.
  3. How it was obtained: two sentences summarising the plan.
  4. What was assumed: values not taken from the paper, one line each.
  5. What would change the answer: the one or two limits that matter.
Best for

The chat's key-findings view, and quick follow-up questions. Too thin for a formal reproduction: technical completeness suffers.

03

IMRaD manuscript

Full manuscript1500+ words · for a study that reproduces several figures

The structure MIT 21W.732 and Purdue OWL teach for a full paper. A single-figure reproduction can't fill its sections without padding, so it is used only for a study that reproduces several of a paper's figures: chosen automatically when the plan targets three or more source figures.

Outline
  1. Abstract (≤ 150 words): objective, method, key result, answer.
  2. Introduction: the question, what the plan records the paper as stating, the hypothesis.
  3. Methods: the plan, covering the model and version, conditions with sources, runs and figures.
  4. Results: per figure, observations and run statistics, reported without interpretation.
  5. Discussion: the answer, comparison with the recorded paper findings, outcome and limitations.
  6. Conclusion: two sentences.
Best for

Reproducing a paper section or a whole paper, written up for readers from outside the project. Put a one-line answer under the title so the conclusion isn't buried.

04

Claim–evidence ledger

Audita table plus 300 words · for verification

Swarthmore's rule that every general statement is supported by data, made literal. Every claim is a row with its evidence and a status.

Outline
  1. Question and verdict: the answer and outcome in one sentence.
  2. Claims: a table of claim | evidence (figure, run or plan finding) | marker | status (supported, partly supported, not supported, not identifiable).
  3. Against the paper: each recorded finding with agree, differ or not comparable.
  4. Assumptions ledger: input, value, provenance, effect if wrong.
  5. What would change the verdict.
Best for

Evaluation runs and reviewers checking calibration. Factuality and calibration are easy to judge in this form; it reads poorly as prose.

05

Memo with technical appendix

Two readers1-page memo + appendices

Purdue OWL's advice to split a report so different readers can get different depth: a one-page memo for the reader who decides, appendices for the reader who checks.

Outline
  1. Memo: purpose, answer, outcome, confidence, any decision needed (for example, which assumed value to confirm).
  2. Appendix A: plan conditions and sources (the conditions sheet).
  3. Appendix B: runs and what differs between them.
  4. Appendix C: figures with captions and computed statistics.
  5. Appendix D: assumed values.
  6. Appendix E: reproduction scripts.
Best for

Sharing with a group lead or a reviewer. The appendices can be generated, so the agent writes only the memo, which is the fastest option to produce.

Rules every template keeps

  1. Open with the answer to the question as asked, and one outcome word.
  2. Keep three sources apart: what the paper states (from the plan, cited), what the figure shows, and what the runs measured (cited to the model).
  3. Use only statistics a tool computed; otherwise write N/A. Never read numbers off a bitmap.
  4. List every value the paper did not give, with the value used and why.
  5. Cite the paper's key statements from the session digest; reopen a section only to check a detail.
