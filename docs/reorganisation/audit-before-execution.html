Tier 1Do today · cannot break the app~5 minutes

Nothing here is imported by anything. The test suite cannot notice.

# 1. create the holding area, and make it invisible to git and the server
mkdir -p dummy
echo "dummy/" >> .gitignore

# 2. stop tracking the committed run artifacts, keep them on disk
git rm -r --cached output_no_cascades
mv output_no_cascades dummy/

# 3. stop pywatershed writing them into the repo root again
echo "*_mass_budget.nc" >> .gitignore

# 4. verify
.venv/bin/python -m pytest -q          # expect 251 passed
.venv/bin/python -c "import app"       # expect the self-check banner
Naming matters more than it looks. A dummy/ folder that is still tracked still ships to the Studio. “Not used by the server” and “not visible to the server” are different requirements — the .gitignore line is what actually satisfies the second one.
